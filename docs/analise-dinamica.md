# Análise dinâmica

## Objetivo

Executar a extensão em ambiente controlado para observar o comportamento real durante a navegação e o uso da ferramenta.

## O que observar

- tráfego de rede
- logs do navegador
- armazenamento local
- eventos disparados
- ações automáticas da extensão
- alterações em páginas acessadas

## Checklist

- [ ] A extensão envia dados para servidores externos?
- [ ] Há ações automáticas sem consentimento?
- [ ] O comportamento muda conforme a página acessada?
- [ ] Há criação de arquivos ou alterações em armazenamento local?
- [ ] O uso de permissões se justifica no contexto?

## Observações

Documentar evidências, capturas e resultados relevantes para a conclusão da análise.
