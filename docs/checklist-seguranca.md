# Checklist de segurança

## Segurança geral

- [ ] A extensão solicita privilégios mínimos
- [ ] O código não coleta dados desnecessários
- [ ] Há validação de entradas e saída de dados
- [ ] Há documentação clara do propósito da extensão
- [ ] Não existem chamadas suspeitas a domínios desconhecidos

## Análise técnica

- [ ] O código foi revisado em busca de funções de rede, coleta e persistência
- [ ] Existem scripts ocultos ou código obfuscado
- [ ] Há uso indevido de storage, cookies ou histórico
- [ ] A extensão realiza ações sem interação do usuário
- [ ] Os dados coletados têm justificativa funcional

## Conclusão

A extensão pode ser considerada segura apenas quando não houver indícios de comportamento malicioso, coleta indevida de dados ou abuso de privilégios.
